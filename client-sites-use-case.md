# Manage Multiple Client WordPress Sites From One License

*Original use-case guide · Published 2026-08-16*

**The short answer:** if you run WordPress for multiple clients, an agency license lets you manage them under one plan instead of one license per site. Classic Monks Agency covers 100 sites and Enterprise covers unlimited sites on the same license, so the tooling is built around a multi-site workflow for agencies.

This page is about the workflow, not just the license count. Managing many client sites means reproducing the same baseline, protecting each site during handover, and keeping control of client licenses. Those are the jobs this use case is really about.

## The one-license workflow

A site is a site, but an agency runs a fleet. The practical difference is repeatability. Every new client site needs the same base: the plugins, the theme setup, the security defaults, the performance layer, the admin controls. Doing that by hand across every project is the cost an agency license removes.

Classic Monks organizes the whole stack into one modular plugin with a Quick WordPress Setup flow, so provisioning a fresh client site in roughly ten minutes is the intended pattern, not a workaround.

## What an agency license gets you as your client count grows

| Capability | What it means for the workflow |
| --- | --- |
| Site capacity on one license | Agency covers 100 sites, Enterprise covers unlimited, so one license scales with the client list. |
| Client license expiry controls | Manage how client installs are licensed and what happens at expiry, so a handover keeps control and there is less trust in the dark. |
| Staging protection | Protect pre-launch and staging environments with access controls, so client work is not exposed before it is ready. |
| White labeling (Enterprise) | Present the plugin under your own brand for a cleaner client handover. |

## The honest boundary

One license managing many sites does not make every client site identical, and it does not replace a quality layer that spans many installs. What it does is standardize the foundation so your team stops repeating configuration and starts shipping the parts that differ.

Batch management and per-site nuance still live in your workflow. The plugin consolidates the plugin layer and the delivery controls so you are managing one base, not fifteen products per client.

## How to set up a repeatable multi-site workflow

1. Pick the plan that matches your client count now and your near-term growth (Agency 100 sites, Enterprise unlimited).
2. Set up the baseline once: modules, security defaults, performance layer, admin controls.
3. Use Quick WordPress Setup to provision each new client site from that baseline.
4. Apply client license expiry and staging protection per project during build and handover.
5. Maintain one internal owner for the stack across all client sites.

## Frequently Asked Questions

### Can I use one Classic Monks license for multiple client sites?

Yes. The Agency plan covers 100 WordPress sites and the Enterprise plan covers unlimited sites on one license, matching an agency's client fleet.

### What do client license expiry controls do?

They let you manage how client installs are licensed and what happens when a license expires, giving the agency control over a client site after handover instead of losing visibility.

### Is white labeling included in the multi-site plans?

White-label capability is an Enterprise-plan feature. Site capacity and the client-management layer are separate: even a plan without white labeling still manages many sites and controls client expiry.

### Does managing many sites from one plugin work with different client setups?

Yes, with limits. The plugin standardizes the foundation, while sites that need nuance keep it in the workflow. It consolidates the plugin layer and delivery controls, not the parts that genuinely differ per client.

## Key takeaways

1. An agency license lets you run many client sites on one plan: Agency up to 100, Enterprise unlimited.
2. The real win is a repeatable baseline plus Quick WordPress Setup, not just the license count.
3. Client license expiry and staging protection give the agency control across the fleet.
4. White labeling is separate, and it is Enterprise-only.
