# How to Use the WooCommerce Tab in Classic Monks: Feature Index

> The WooCommerce tab in Classic Monks adds 49 features across 11 subtabs. This index links to every per-feature guide, organized by subtab for fast navigation.

## Key Takeaways

- 49 per-feature docs covering the full WooCommerce tab
- 11 subtabs: Status, Product Swatches, Single Product, Checkout, One Click Checkout, Orders, Coupons, My Account, Optimization, Redirection, Email
- Each feature has its own dedicated guide with frontmatter, FAQ, and advanced developer options
- Performance features (Optimization) and conversion features (Coupons, BOGO) are the highest-impact

## Status

The Status subtab is a read-only diagnostic panel for the WooCommerce integration. It shows WordPress version, WooCommerce version, and any compatibility warnings.

## Product Swatches

Transform WooCommerce product attributes into visual swatches (color circles, image thumbnails, or text labels). Improves the shopping experience and increases conversion rates.

## Common Combinations

- **Performance focused**: Enable Optimization features (9 features) to improve site speed.
- **Conversion focused**: Enable BOGO + URL Coupons + Auto-Apply Coupons + Checkout Product Selector for maximum conversion.
- **B2B / wholesale**: Enable User Role Coupon Restrictions + Role-Based Maximum Discounts + Direct Checkout Links.
- **Digital products**: Enable Auto-Completion + Custom Order Status + Disable Order Number Column.
- **Multi-vendor / marketplace**: Enable Custom Order Columns (especially Customer Type, Customer Since, Shipping Method).
