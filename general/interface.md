# How to Use the Interface Tab in Classic Monks: Feature Index

> The Interface tab in Classic Monks adds 29 features across 6 subtabs. This index links to every per-feature guide, organized by subtab.

## Key Takeaways

- 29 features across 6 subtabs
- 6 subtabs: Folders, Admin Notices, Form Desk, Preloader, Laser Loader, Experience
- Each feature has its own dedicated guide with frontmatter, FAQ, and advanced developer options
- The Folders subtab is the most feature-rich (8 features covering media management)

## Folders

The Folders subtab adds a complete media folder management system. 8 features.

| Feature | Description | Guide |
|---------|-------------|-------|
| **Folder Manager** | Organize media into virtual folders. 3 sub-options. | [View guide](interface/interface-folder-manager.md) |
| **Folder Download (ZIP)** | Download folder contents as ZIP archives. | [View guide](interface/interface-folder-download.md) |
| **Folder Duplication** | Duplicate folder structures. | [View guide](interface/interface-folder-duplication.md) |
| **Gallery Shortcode** | `[cm_gallery]` shortcode for folder-based galleries. | [View guide](interface/interface-gallery-shortcode.md) |
| **Quick Inspect** | Modal-based media editing. | [View guide](interface/interface-quick-inspect.md) |

## Admin Notices

The Admin Notices subtab manages WordPress admin notices. 1 feature.

| Feature | Description | Guide |
|---------|-------------|-------|
| **Admin Notices Manager** | Dismiss, hide, or rearrange admin notices. | [View guide](interface/interface-admin-notices-manager.md) |

## Form Desk

The Form Desk subtab centralizes form entries from multiple plugins. 1 feature (2 integrations).

| Feature | Description | Guide |
|---------|-------------|-------|
| **Form Desk** | Centralized form entry management. Supports Bricks Builder + Fluent Forms. | [View guide](interface/interface-form-desk.md) |

The Preloader subtab adds loading animations. 4 features.

| Feature | Description | Guide |
|---------|-------------|-------|
| **Preloader** | Loading animation on page navigation. | [View guide](interface/interface-preloader.md) |
| **Mobile-Specific Customization** | Different preloader for mobile devices. | [View guide](interface/interface-preloader-mobile.md) |
| **Disable in Bricks Builder** | Disable preloader in the Bricks editor. | [View guide](interface/interface-preloader-bricks.md) |

The Laser Loader subtab adds a laser-style progress bar. 8 features.

| Feature | Description | Guide |
|---------|-------------|-------|
| **Laser Loader** | Laser-style progress bar during page load. | [View guide](interface/interface-laser-loader.md) |
| **Disable in Bricks Builder** | Disable in the Bricks editor. | [View guide](interface/interface-laser-loader-bricks.md) |

## Experience

The Experience subtab adds page transitions and admin UX features. 5 features.

| Feature | Description | Guide |
|---------|-------------|-------|

## Common Combinations

- **Media-heavy site**: Folder Manager + Folder Download + Gallery Shortcode + Quick Inspect
- **Professional loading experience**: Laser Loader (with Shadow + Percentage) + Page Transitions + Reduced Motion
- **Bricks Builder workflow**: Preloader (disable in Bricks) + Laser Loader (disable in Bricks) + Page Transitions
- **Admin UX**: Admin Notices Manager + Admin Bar Bottom + Transitions in Admin
