# How to Use Content Utilities in WordPress

> The SEO and Visibility section in Classic Monks Core groups five independent features that control how your content is treated by search engines and visitors. Each feature has its own dedicated guide.

## About This Index

This page is a directory of all content utility features in Classic Monks. Each feature is a toggle in the **Core > Content > SEO and Visibility** section, but each has its own documentation.

## SEO & Visibility Features

| Feature | Description | Guide |
|---------|-------------|-------|
| **Add nofollow to External Links and Open in New Tab** | Automatically add `rel="nofollow"` and `target="_blank"` to all external links in your content. | [View guide](core-nofollow-external-links.md) |
| **Enable Nofollow for Post Types** | Add a noindex, nofollow meta tag to entire post types. Per-post-type control with three modes. | [View guide](core-nofollow-post-types.md) |
| **Disable Core Sitemaps** | Remove WordPress 5.5+ built-in XML sitemaps. Prevent conflicts with SEO plugin sitemaps. | [View guide](core-disable-core-sitemaps.md) |
| **Exclude Noindex Posts from Search Results** | Hide posts marked noindex from WordPress's internal search results. | [View guide](core-exclude-noindex-from-search.md) |
| **Enable Search Engine Visibility Status** | Show indexing status in the admin bar. Auto-discourage indexing on URLs that don't match your Live Site URL. | [View guide](core-search-engine-visibility-status.md) |
