# How to Manage Content in WordPress

> The Content subtab in Classic Monks Core groups features that change how you create, organize, preview, and redirect content. Each feature has its own dedicated guide with configuration, troubleshooting, and developer filters.

## About This Index

This page is a directory of all content management features in Classic Monks. Each feature is a toggle in the **Core > Content** subtab, but each has its own documentation because the configuration, troubleshooting, and edge cases are different.

Use the table below to find the feature you need, then click through to the dedicated guide for full details.

## Custom Post Type & Taxonomy Controls

| Feature | Description | Guide |
|---------|-------------|-------|
| **Post Type Switcher** | Change a post's type (post to page, post to custom post type) while preserving metadata and taxonomies. | [View guide](core-post-type-switcher.md) |
| **Taxonomy Switcher** | Migrate posts between categories, tags, and custom taxonomies. Bulk-migrate many posts at once. | [View guide](core-taxonomy-switcher.md) |
| **Order Post Types** | Drag-and-drop reordering of posts in the list table. Configure which post types are reorderable. | [View guide](core-order-post-types.md) |
| **Enable Custom Taxonomy Filters** | Dropdown filter menus in the post list table for every registered taxonomy. | [View guide](core-custom-taxonomy-filters.md) |

## Query & Routing Hooks

| Feature | Description | Guide |
|---------|-------------|-------|
| **Global 404 Redirect** | Redirect all 404 errors site-wide to a chosen destination (Home, Shop, specific page, or custom URL). | [View guide](core-global-404-redirect.md) |

## Conditional Display

| Feature | Description | Guide |
|---------|-------------|-------|
| **Conditional Menu Items** | Show or hide menu items by user role, device, page, or custom criteria. AND/OR logic. | [View guide](core-conditional-menu-items.md) |

## Editorial Workflow

| Feature | Description | Guide |
|---------|-------------|-------|
| **Disable Author Edit** | Prevent non-admin users from changing the author of a post. | [View guide](core-disable-author-edit.md) |
| **Enable Content Duplication** | One-click duplication of any post or page. Preserves all metadata and taxonomies. | [View guide](core-content-duplication.md) |
| **Public Post Preview** | Share unpublished posts via a secure, time-limited URL. Optional password protection. | [View guide](core-public-post-preview.md) |
| **Auto Featured Image** | Automatically set the first image in post content as the featured image. | [View guide](core-auto-featured-image.md) |
| **Enable Classic Feedback** | Add a "Was this article helpful?" yes/no widget. Tracks votes. Bricks dynamic data tags. | [View guide](core-classic-feedback.md) |
| **Disable Scheduled Deletion** | Prevent WordPress from auto-deleting trashed posts after 30 days. | [View guide](core-disable-scheduled-deletion.md) |
