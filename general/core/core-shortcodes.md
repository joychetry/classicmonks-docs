# How to Use Shortcodes and Filter Utilities in WordPress

> The Shortcode and Filter Utilities section in Classic Monks Core provides four specialized shortcodes for tag display, SEO meta descriptions, time format conversion, and currency conversion. Each has its own dedicated guide.

## About This Index

This page is a directory of all shortcode utilities in Classic Monks. Each shortcode is a toggle in the **Core > Content > Shortcode and Filter Utilities** section, with its own documentation.

## Shortcodes

| Shortcode | Purpose | Guide |
|-----------|---------|-------|
| `[tags_no_comma]` | Display post tags without the default comma separator. Configurable separator. | [View guide](core-tags-no-comma-shortcode.md) |
| `[rm_excerpt]` | Display the RankMath SEO meta description as visible page content. | [View guide](core-rm-excerpt-shortcode.md) |
| `[cm_time_format]` | Convert 24-hour time to 12-hour with AM/PM. Plus global filter for theme-level time displays. | [View guide](core-time-format-conversion.md) |
| `[cm_currency_converter]` | Currency selector dropdown. Convert `<span class="cm-price">` elements to visitor's chosen currency. | [View guide](core-currency-converter.md) |
