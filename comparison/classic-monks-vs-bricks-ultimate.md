# Classic Monks vs Bricks Ultimate: Which Bricks Addon Do You Actually Need?

*Comparison page · Verified August 17, 2026 · Prices and feature scope checked against official pages on the same date*

Bricks Ultimate (officially BricksUltimate, at bricksultimate.com) is a premium add-on built exclusively for Bricks Builder, focused on WooCommerce storefront elements and query loop providers. Classic Monks is a WordPress-wide stack with 162 features for Bricks Builder plus security, performance, WooCommerce operations, admin tools, and white label. Bricks Ultimate goes deeper on Bricks-native storefront blocks. Classic Monks goes wider across the entire site.

I build Classic Monks, so this page will be honest about where Bricks Ultimate wins. It wins on Bricks-native storefront depth, and it has a cheap entry point for Bricks-only shops.

> **Quick verdict:** Choose Bricks Ultimate when you run Bricks-only sites and need its specific elements, especially WooCommerce storefront blocks, form stylers, or ACF and Metabox loop providers. Choose Classic Monks when you manage client sites and want one plugin to cover Bricks features plus security, performance, store operations, admin cleanup, and white label. They can also run together, because they are different layers of the same builder.

This comparison was checked on **August 17, 2026** against the official [BricksUltimate site](https://www.bricksultimate.com/), the [Classic Monks pricing page](https://classicmonks.com/pricing/), the [Classic Monks features page](https://classicmonks.com/features/), and the Classic Monks feature inventory.

**How we classified the comparison:** We marked a workflow as covered when Classic Monks supports the core job in its current implementation or documentation. Bricks Ultimate elements with no named Classic Monks counterpart stay in a separate list, because this is a workflow comparison, not a claim that similarly named features behave identically.

**About the name:** the official site sells this add-on as BricksUltimate, commonly written as Bricks Ultimate. It is a third-party add-on for Bricks Builder, not by Bricks' own team, and it requires a Bricks license to work.

## What Does Classic Monks Cover That Bricks Ultimate Does Not

Bricks Ultimate is an element pack for one builder. It does not secure the site, speed up the front end, run store operations, clean up the admin, or hand a site to a client. Those jobs are the rest of Classic Monks.

**Security layer.** Login lockdown, Cloudflare Turnstile, math CAPTCHA, 2FA with authenticator app and email OTP, custom login URL, user enumeration protection, XML-RPC and REST API controls, content protection, and Staging Protection with HTTP auth and access tokens. Bricks Ultimate has no security features.

**Performance.** The full Performance tab: WordPress optimizations, Heartbeat control, Image Converter to WebP and AVIF, CDN rewrite, Assets Manager, lazy loading with lazy rendering and negative loading, and predictive page preloading. Bricks Ultimate is not a performance plugin.

**WooCommerce operations on top of the builder.** Classic Monks handles the store beyond layout: product swatches, checkout field cleanup, direct checkout links, URL and auto-apply coupons, BOGO deals, order statuses and columns, My Account redirects, and store email controls. Bricks Ultimate builds storefront layout; Classic Monks runs the store.

**Admin, media, email, and setup.** Admin Menu Manager, Top Toolbar Manager, Admin Notices Manager, Remove Dashboard Widgets, Folder Manager, Form Desk, email controls, Quick WordPress Setup, and settings export and import.

**White label and agency delivery.** Enterprise plan: rebrand the plugin, hide it from the plugins list, priority support, and priority feature requests. Bricks Ultimate offers white label only on its unlimited tier, and only for the add-on itself.

**The rest of the stack.** AI tools, Code Manager with syntax validation, safe mode, and fatal-error recovery, content duplication, post type and taxonomy switchers, short links, media replacement, and 260+ documentation pages.

Because Classic Monks is builder-agnostic, all of these stay active on Gutenberg, Elementor, Breakdance, or plain WordPress sites. Bricks Ultimate has no effect outside Bricks.

*Bottom line for this category: Bricks Ultimate does one job. Classic Monks does the rest of the site.*

## What Does Bricks Ultimate Cover That Classic Monks Does Not

This is where the comparison stays honest. Bricks Ultimate is the deeper Bricks-native storefront tool, and its element catalog is its reason to exist.

- **WooCommerce storefront elements.** Checkout Builder, Mini Cart Builder, Order Bumps, Applied Coupons, Cart Counter, Cart Content, My Account Navigation, Thank You Page builder, Free Shipping Notice, Purchasable badges, Linked Variations, and Swatches for Loop. Classic Monks has WooCommerce elements and store operations, but not a visual checkout builder, mini cart builder, or order bump element.
- **Form stylers.** Dedicated styling elements for Contact Form 7, Gravity Forms, Fluent Forms, Piotnet Forms, WPForms, WS Forms, and WPGB Facets. Classic Monks manages form submissions through Form Desk, but does not style third-party form plugins.
- **Query Loop Providers.** 28 providers covering ACF checkboxes, galleries, and post objects, Metabox galleries, relationships, and checkboxes, custom WP queries, custom taxonomies, product lists (best selling, featured, on sale, top rated, related, cross-sells, upsells, recently viewed), and customer orders, wishlist items, and compare items. Classic Monks has query elements for comments, reviews, product gallery, menu, recently viewed, and wishlist, but not this provider list.
- **General elements Classic Monks does not ship.** AJAX Popup Builder, Off Canvas, Sliding Menu, Accordion Menu, Business Hours, Highlighted Heading, Dual Color Text, Reading Progress Bar, Flex Gallery, Slim Gallery, and most of the form stylers. Classic Monks ships an overlapping set (tables, image compare, countdown, star ratings, wishlist, breadcrumbs, back to top), but not these specific elements.
- **Pricing entry for Bricks-only shops.** A 10-domain license at $79 one-time covers a small Bricks-only site for less than any Classic Monks license.

The cleanest way to read it: if a site needs a specific Bricks Ultimate element, Bricks Ultimate is the tool that has it.

*Bottom line for this category: Bricks Ultimate's element catalog fills gaps that Classic Monks does not attempt to match, especially on storefront layout.*

## How Their Bricks Feature Sets Actually Compare

Classic Monks ships 162 features for Bricks Builder, verified on its features page, grouped as elements, controls, animations, dynamic data, conditions, interactions, import and export, and optimization. The element set includes 30+ exclusive elements in 7 categories: text, core, background, media, sliders, buttons, and cursors. Controls cover tooltips, mini cart quantity, swatch controls in Add to Cart, read more and less, tab and slider behavior, custom cursor effects, and per-element lazy loading and preloading. Dynamic data covers WordPress core tags, WooCommerce tags, media, taxonomy, menu, comments, and reviews. Conditions cover core, user, content analysis, taxonomy, media, and WooCommerce rules. Interactions run 21 triggers and 22 actions.

Bricks Ultimate ships 35 general elements, 32 WooCommerce elements, 28 Query Loop Providers, and a dynamic tag set with 34 general and roughly 95 WooCommerce tags, plus conditions and interactions. Its general elements are biased toward navigation, layout, and storefront helpers: menus, off canvas, popup, form stylers, comparison tables, countdowns, and galleries. Its Woo side is the deepest part: checkout, cart, coupons, swatches, badges, and order bumps.

The overlap is real: both offer tables, before and after images, countdowns, wishlist elements, star ratings, and breadcrumbs in some form, and both expose dynamic data, conditions, and interactions. The difference is direction. Bricks Ultimate concentrates on storefront layout inside Bricks. Classic Monks covers storefront needs partly, then continues into security, performance, and the rest of the site.

*Bottom line for this category: Both are substantial Bricks add-ons. Classic Monks has more features total; Bricks Ultimate has more depth in storefront elements and query loop providers.*

## Can You Use Classic Monks and Bricks Ultimate Together?

Yes. Both are Bricks add-ons and they operate at different layers. Classic Monks brings elements, controls, dynamic data, conditions, and interactions, plus the non-Bricks stack. Bricks Ultimate brings its specific element catalog. There are no documented conflicts between the two, and the practical rule is to avoid duplicating the same element on the same template.

Pick one owner for:

- Swatches: Classic Monks WooCommerce swatches versus Bricks Ultimate Swatches for Loop
- Wishlist and compare: Classic Monks wishlist elements versus Bricks Ultimate wishlist and compare elements
- Countdowns, tables, image compare, star ratings: both ship these; use one per template
- BOGO and bundles: Classic Monks BOGO deals versus Bricks Ultimate Buy X Get Y Pro and Frequently Bought Together
- Recently viewed products: Classic Monks recently viewed query versus Bricks Ultimate recently viewed provider

Duplicate elements just add confusion in the builder panel. Enable only what each template uses.

## How to Migrate from Bricks Ultimate to Classic Monks

Bricks Ultimate is not a full replacement for Classic Monks, and this is a partial migration in the other direction too. Do it on staging:

1. **Inventory first.** List every Bricks Ultimate element and provider used in your templates, per template. Do not skip this step. Missing one element on a live page is the most common migration bug.
2. **Map what exists.** For each Bricks Ultimate element, check if Classic Monks covers the core job: swatches, BOGO deals, wishlist, recently viewed, tables, image compare, countdown, star ratings, breadcrumbs, back to top, buy now, reviews, comments and product queries.
3. **Mark the gaps.** List the ones with no Classic Monks counterpart: checkout builder, mini cart builder, order bumps, applied coupons, form stylers, AJAX popup, off canvas, accordion menu, sliding menu, business hours, and the ACF and Metabox loop providers.
4. **Decide per gap.** Keep Bricks Ultimate for the gaps, or rebuild those templates with classic Bricks elements plus Classic Monks conditions and dynamic data.
5. **Test on staging.** Builder editing, front-end output, WooCommerce checkout, wishlist and compare behavior, and forms. Clear all caches between tests.
6. **Swap one template at a time.** Remove Bricks Ultimate elements from templates only after Classic Monks coverage verifies in the builder.
7. **Keep both active.** Do not uninstall Bricks Ultimate until the soak period passes on live sites. A two-week soak is the minimum for WooCommerce sites with order flow.

## Who Should Choose Which

**Choose Bricks Ultimate** if you run Bricks-only sites and need its specific elements: checkout builder, mini cart builder, order bumps, form stylers, accordion and sliding menus, AJAX popup, off canvas, or the ACF and Metabox loop providers.

**Choose Classic Monks** if you manage client sites and want one license to cover Bricks features plus security, performance, WooCommerce operations, admin cleanup, and white label.

**Choose Classic Monks** if you want a one-time license across 100 or more sites, or if you want to consolidate a stack of plugins instead of adding another Bricks add-on.

**Keep both** if Classic Monks is the operating stack and Bricks Ultimate's specific elements earn their keep. These two coexist more easily than most add-on pairs, because their overlap is element-level rather than global settings.

## Frequently Asked Questions

### Can Classic Monks replace Bricks Ultimate?

Partially. Classic Monks covers many common Bricks element needs, WooCommerce swatches and BOGO deals, wishlist and recently viewed queries, and adds the WordPress stack beyond the builder. It does not ship checkout builder, mini cart builder, order bumps, form stylers, AJAX popup, off canvas, or the ACF and Metabox loop providers. Keep Bricks Ultimate where those matter.

### Does Bricks Ultimate work without Bricks Builder?

No. Bricks Ultimate requires the Bricks Builder theme and WordPress 6.0+ with PHP 8.0.x, per its official site. Classic Monks works with or without Bricks; its Bricks features simply stay inactive when the builder is not installed.

### Is Bricks Ultimate a one-time purchase?

Yes. Official pricing is one-time by domain count: $79 for 10, $109 for 20, $149 for 50, $249 for 100, $699 for unlimited, with lifetime updates and support. Classic Monks offers yearly plans from $39 or one-time LTD plans from $299.

### Can I use Classic Monks and Bricks Ultimate on the same site?

Yes. They are different layers of Bricks and do not conflict. Avoid using both for the same job: pick one owner for swatches, wishlist, compare, countdowns, tables, image compare, and BOGO tools.

### Which is better for a WooCommerce store built in Bricks?

Bricks Ultimate for storefront layout: checkout builder, mini cart, order bumps, applied coupons, cart counter, and swatches for loop. Classic Monks for store operations on top of that: coupons, BOGO deals, checkout fields, order tools, redirects, plus security and performance around the store.

### Does Bricks Ultimate include white label?

Only on the $699 Unlimited tier, and it applies to the add-on itself. Classic Monks includes white label on Enterprise (yearly or LTD), along with hiding the plugin from the plugins list, priority support, and priority feature requests.

### Is Classic Monks a Bricks-only plugin?

No. Classic Monks is builder-agnostic and works with Gutenberg, Elementor, Breakdance, and plain WordPress. Bricks features are one part of the 393+ feature stack and activate only when Bricks is installed. Bricks Ultimate, by contrast, does nothing outside Bricks.

## Key Takeaways

1. **Bricks Ultimate is a deep, Bricks-only storefront tool.** It ships 35 general elements, 32 WooCommerce elements, 28 Query Loop Providers, and deep dynamic tags, priced one-time from $79.
2. **Classic Monks is a WordPress-wide stack.** It ships 162 Bricks features inside a 393+ feature stack, priced yearly or one-time from $299.
3. **Bricks Ultimate wins on Bricks-native storefront depth.** Checkout builder, mini cart, order bumps, form stylers, and ACF and Metabox loop providers are its strongest case.
4. **Classic Monks wins on breadth.** Security, performance, WooCommerce operations, admin tools, media, email, AI, and white label, with or without Bricks installed.
5. **The top-end math favors Classic Monks.** $599 Enterprise LTD includes white label and the whole stack, versus $699 Unlimited for Bricks Ultimate plus a separate Bricks license.
6. **They coexist cleanly.** Assign one owner per duplicated element, and you can keep Bricks Ultimate for its unique elements.
